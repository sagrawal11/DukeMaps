# DukeMaps

Walking-directions web app for Duke's campus that shows the search algorithms behind
Google Maps at work — BFS, DFS, Dijkstra, A\*, bidirectional Dijkstra, and contraction
hierarchies, all hand-written and animated on the map.

Fully static (runs in the browser, deploys to GitHub Pages). See `BRIEF.md` for the
full spec and `CLAUDE.md` for how this project is built. A complete README with
screenshots and an architecture overview lands in Phase 7.
